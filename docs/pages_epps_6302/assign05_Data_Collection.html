1. Searching GovInfo for the 10 most recent hearings

body <- list(
  query      = 'collection:(CHRG) AND "Committee on Foreign Relations"',
  pageSize   = 10,
  offsetMark = "*",
  sorts      = list(list(field = "publishdate", sortOrder = "DESC"))  # newest first
)

found <- request("https://api.govinfo.gov/search") |>
  req_url_query(api_key = Sys.getenv("GOVINFO_API_KEY")) |>   # key read from .Renviron
  req_body_json(body) |>
  req_perform() |>
  resp_body_json()

ids <- vapply(found$results, \(r) r$packageId, character(1))   # one ID per hearing

2. Downloading the PDFs into a folder data-raw listed in .gitignore

out_dir <- here::here("data-raw", "sfrc_hearings")   # data-raw/ is in .gitignore
dir.create(out_dir, recursive = TRUE, showWarnings = FALSE)

log <- data.frame()
for (r in found$results) {
  id   <- r$packageId
  dest <- file.path(out_dir, paste0(id, ".pdf"))
  url  <- paste0("https://api.govinfo.gov/packages/", id, "/pdf")

  # Download; if it fails, record the error instead of stopping
  status <- tryCatch({
    request(url) |>
      req_url_query(api_key = Sys.getenv("GOVINFO_API_KEY")) |>
      req_perform(path = dest)
    "ok"
  }, error = \(e) paste("failed:", conditionMessage(e)))

  # One log row per hearing
  log <- rbind(log, data.frame(
    timestamp  = format(Sys.time(), "%Y-%m-%d %H:%M:%S"),
    package_id = id,
    title      = r$title,
    date       = r$dateIssued,
    url        = url,          # without the key
    status     = status,
    size_kb    = if (file.exists(dest)) round(file.size(dest) / 1024, 1) else NA
  ))
  Sys.sleep(1)                 # be polite to the API
}

4. Report

This assignment was particularly difficult because the instructions on the pdf file do not match the R govtdata01.R file available on Teams. For example, the assignment instructions mention parts A and B in that file. There are no indications of these parts. Also, the script given in the pdf instructions, are so different from govtdata01.R that was difficult to make sense of the task. For this reason, I had to rely on Claude Code to accomplish what was asked.

Answers:

  1. The data donwloaded in .pdf are useful, but as the files are primarily text, they would require specific processes of text analysis via machine learning or LLM even for table extraction.

  2. The metadata donwloaded is useful for meta analyses, such as reports on broad topics that have been addresed with more frequency, or topic assessments.

  3. The API in this case gave me the complete reports, with the detail that those reports are mainly text data, which require special processing.
