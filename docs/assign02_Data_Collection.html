Assignment 02 - EPPS 6302

This assignment addresses term searches on Google Trends

The following notes reproduce the scripts used for each search, an overview of the scraped data and the respective plots.

Installing needed packages

library(gtrendsR)
library(readr)
library(DT)

Initial search

Query record

  • Terms: Trump, Harris, election

  • Countries: United States

  • Group: Web

  • Time window: Last 5 years

  • Category: All categories (news, youtube, images etc)

TrumpHarrisElection = gtrends(c("Trump","Harris","election"), 
                              onlyInterest = TRUE, 
                              geo = "US", 
                              gprop = "web", 
                              time = "today+5-y", # last five years
                              category = 0 
) 
df=TrumpHarrisElection$interest_over_time
plot(TrumpHarrisElection)
DT::datatable(TrumpHarrisElection$interest_over_time)

Updated Search

Query record

query2 <- gtrends("immigration", time = "all")
