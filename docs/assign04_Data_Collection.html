1. Warm-up: books.toscrape.com

scrape_books <- function(url) {
  pg <- read_html(url)
  tibble(
    title  = pg |> html_elements("article.product_pod h3 a") |> html_attr("title"),
    price  = pg |> html_elements("article.product_pod p.price_color") |> html_text2(),
    rating = pg |> html_elements("article.product_pod p.star-rating") |>
               html_attr("class") |> str_remove("star-rating ")
  ) |>
    mutate(price_gbp = parse_number(price),
           stars     = match(rating, c("One", "Two", "Three", "Four", "Five")))
}

3. The World Bank API

# One call. start = 1960 so countries whose last report is old (e.g. Iran) still appear
reserves_api <- WDI(indicator = c(reserves_wb = "FI.RES.TOTL.CD"),
                    start = 1960, end = 2025, extra = TRUE)

# Latest available year per country, without regional aggregates
wb_latest <- reserves_api |>
  filter(region != "Aggregates", !is.na(reserves_wb)) |>
  group_by(iso3c) |>
  slice_max(year, n = 1, with_ties = FALSE) |>
  ungroup() |>
  select(iso3c, country_wb = country, year_wb = year, reserves_wb)

b) Comparing results

The two datasets are not completely the same, with several discrepancies, such as:

  • The two sources are not measuring the same moment. The World Bank series is annual and end-of-year: most economies report 2025, a smaller group stops at 2024, and a few are much older - Most of the gap for large holders is time, not disagreement. For example, the World Bank reports India at US$700.1 bn for end-2025, while Wikipedia reports.
  • The country list is no the same, ofr example Taiwan appears on Wikipedia but has no World Bank series

c) When is scraping the right tool?

Scraping is a great tool when the data are publicly visible but are not available via API for mass download. Here it was the wrong choice because the World Bank had a better documented and API-available source.

4. Data plan

As a PhD Student in Public and Nonprofit Management, my main research topic is public sector auditing and financial oversight. The main agency in the United States that conducts public sector auditing is the Government Accountability Office. My research includes text analysis to identify the main topics and government areas that encompass the most anomalies (errors, fraud etc). To perform my intended research, I depend on the availablity of an API suitble for mass download of GAO reports and recommendations.

However, the agency does not provide an open API for recent data, only for the reports from 1994 to 2008, which is not as relevant as the most recent reports. After reaching out directly to the GAO, I was referred to a research department in the agency, which I expect to be able to provide some solution for direct access to the data.

As of now, I don’t see how a robots.txt would affect my research since the needed API is not available. Since the data exists, but is not easily available to the public, I can not indicate what the rate limits, and cache issues I would have encountered.

I am looking forward to finding alternative ways after I can complete a conversation with their research department.
